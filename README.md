# Análise Operacional e Métricas de Desempenho em Contact Center

## Descrição do Projeto
Este projeto consiste na análise detalhada de **3.000 registos de interações** de suporte e operações de *Contact Center*. O objetivo principal foi auditar, tratar e explorar métricas operacionais chave como **AHT (Average Handling Time)**, **THT (Total Handling Time)**, **QA Score (Qualidade)** e **NPS (Satisfação do Cliente)**.

A análise foi estruturada em **10 perguntas de negócio**, culminando na criação de tabelas dinâmicas e respetivos gráficos.

---

## Tecnologias e Ferramentas Utilizadas
* **SQL:** Consultas analíticas para agregação de dados e cálculo de métricas operacionais.
* **Google Sheets:** Limpeza de dados brutos, criação de tabelas dinâmicas, modelos de cálculo e construção do Dashboard de gráficos.
